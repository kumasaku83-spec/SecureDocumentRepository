SDR (Secure Document Repository) v2.02 ヘルプ

🔐 SDR とは？

SDRは、ブラウザの標準機能（Web Crypto API / IndexedDB）のみを使用し、外部サーバーに一切データを送信せずにファイルを暗号化・管理する完全ローカルのセキュアファイル管理アプリです。

v2.02では、複数のレポジトリを独立して管理できるマルチリポジトリ機能や、CSVファイルのネイティブ表示・スプレッドシート形式での編集機能、さらに全文検索時のハイライト機能を搭載しています。

🚀 基本的な使い方

  1. ファイルの追加: お使いのPCから左側の「ツリー（フォルダ階層）」の任意のフォルダへ、ファイルをドラッグ＆ドロップしてください。自動的に暗号化されて保存されます。（※ブラウザのメモリ負荷を防ぐため、1ファイルあたり20MB以下に制限しています）
  2. テキスト/CSVの作成と編集: 余白やフォルダを右クリックして「新規テキストファイル」または「新規CSVファイル」を作成できます。エディタ内で編集した内容は「変更を保存」ボタンで即座に暗号化されて保存されます。
  3. ファイルの閲覧: ツリーからファイルをクリックすると、中央の画面でオンメモリで復号され、プレビューが表示されます（画像、PDF、CSV、各種テキストファイルに対応）。
  4. ファイルの検索: 左上の検索窓に文字を入力すると、ファイル名およびテキスト/CSVの中身（本文）を検索し、該当箇所がハイライトされます。
  5. ファイルの操作: ツリー上のフォルダやファイルを「右クリック」するとメニューが開き、名前の変更、別のフォルダへの移動、削除、新規フォルダの作成が行えます。
  6. ファイルの取り出し: プレビュー画面右上の「復号してダウンロード」ボタンを押すと、元の状態のファイルとしてお使いのPCに保存できます。

🛡️ セキュリティと制限事項

  • UIテーマ対応: ダークモードとライトモードの切り替えに対応しました。ヘッダーの太陽/月アイコンから手動で切り替えるか、OSの設定に自動的に追従します。
  • 完全なXSS対策: ファイル名やフォルダ名に悪意のあるスクリプトが含まれていても、テキストとして安全にエスケープ処理され、実行されることはありません。
  • メモリのゼロクリア: ファイルを復号してメモリ上に展開した直後や、バックアップ処理の完了時に、意図的なゼロクリアを実施し、メモリ空間への平文データ残留を防ぎます。
  • ブラウザのキャッシュ消去によるデータ消失: データ・設定はすべてブラウザの内部ストレージ（IndexedDB）に保存されています。ブラウザの「閲覧履歴データの消去」や「サイトデータの削除」を行うと、保存した全ファイルが完全に消失します。必ず定期的に全データバックアップを取得してください。
  • マスターパスワードの紛失: パスワードやSaltはIndexedDB内のみで完結します。初回設定時のマスターパスワードを忘れると、二度とデータを復号（復元）することはできません。

📦 エクスポートとインポート（sdrpack）

特定のフォルダやファイルだけを別のPCや別のブラウザに移行したい場合に使用します。

  • エクスポート: フォルダを右クリックし「エクスポート」を選択します。専用のパスワード（8文字以上）を設定すると、そのフォルダ以下の全データが暗号化された .sdrpack ファイルとしてダウンロードされます。
  • インポート: 取り込み先のフォルダ（またはルートメニュー）から「インポート」を選択して .sdrpack ファイルを読み込ませ、エクスポート時に設定したパスワードを入力すると復元されます。

このレポジトリ内のすべてのデータと設定を消去し、初期状態に戻したい場合は以下から実行できます。
